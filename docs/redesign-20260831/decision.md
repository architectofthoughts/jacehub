## 파트너가 꼽은 문제
1. 허브인데 카드가 기능적이기만 해서 들어가고 싶지 않음
2. 대안으로 만든 로비가 메인이 아니고, 즐겨찾기한 앱만 노출
3. 앱이 레포명/홈페이지명으로 저장돼 역할이 안 보이고, 설명이 GitHub description 의존이라 비어 있는 앱이 많음

| 노출 기준 | **`catalog.json` 화이트리스트**(git 정본). API에서 잡히지만 미등록인 프로젝트는 관제 레이어 격납고에 '미등록'으로 접힘 |
| 정보 정본 | `catalog.json` — 표시명·역할 태그·섹션·URL. GitHub description 의존 제거, KV 로비 메타 폐기 |

| 카드 시각 | 아이콘 타일로 식별 → **탭하면 디테일 시트(스크린샷·설명·배포 정보·큰 열기 버튼)**, 항상 2탭 진입. 스크린샷은 헤드리스 캡처 자동화, 레포 자산 |
| 관제 깊이 | **슬림** — 카드 상태점 + 격납고·미검수·퇴역후보·내부 섹션 + 설정 모달(토큰·볼트). 레이더 히어로·CSV·리포트 복사·정렬 제거. 즐겨찾기 → '고정' 행 |
| 이름·분류 | 한글 표시명 + 슬러그 부제 + 한 줄 역할 태그. 정문 섹션 5: 게임 / 생활·생산성 / 도구·작업장 / 기록·아카이브 / 후추네. 비정문 섹션 3: 미검수 / 퇴역 후보 / 격납고 |
