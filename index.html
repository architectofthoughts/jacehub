토큰 · 보관소

Cloudflare 토큰을 넣으면 정문 위에 관제 레이어(배포 상태점 · 미검수 · 퇴역 후보 · 격납고 · 내부)가 켜집니다. 토큰은 이 기기의 localStorage에만 저장돼요.

Workers & Pages → Overview 페이지 우측에서 확인할 수 있습니다.

My Profile → API Tokens → Custom Token → Pages:Read + Workers Scripts:Read (+ Cloudflare Tunnel:Read면 내부 서비스 헬스까지)

GitHub → Settings → Developer settings → Personal access tokens → repo 권한

Vercel → Account Settings → Tokens → Create. Hobby 계정이면 Full Account 스코프로 OK.

보관소 연결됨 — 고정 앱이 PIN 봉투로 동기됩니다

저장할 때 설정한 6자리 PIN을 입력하면 토큰과 고정 앱 목록을 불러옵니다.

위에 입력한 토큰을 클라우드에 암호화해 저장합니다. 6자리 PIN만 기억하면 어디서든 불러올 수 있고, 같은 PIN으로 저장하면 덮어쓰입니다.
